关于我

我是一名专注 Java 后端方向的开发者，日常主要和 Spring Boot、MyBatis、Redis、MySQL 打交道，做过外卖后台、点评平台、校园商城等完整项目。

在项目里，我比较关注缓存设计、并发安全和接口规范：用 Redis 处理缓存穿透与击穿、用分布式锁解决超卖、用 AOP 统一记录日志，并通过 Swagger 维护接口文档。

除了后端，我也会用 Vite + Tailwind 写前端页面，用 Kotlin 写 Android 小应用，还做过编译原理实验和几个小游戏。
